# Booklist Tool

A simple web app to manage a personal reading list. Built with Node.js, Express and MongoDB.

## Features

- Add, edit and delete books
- Mark books as read or unread
- Book detail page
- Search books by title or author
- Validation with error messages in forms
- Responsive layout (mobile, tablet, desktop)
- 404 error page

## Tech Stack

- Node.js
- Express
- MongoDB + Mongoose
- EJS
- Vanilla JavaScript

## Local Setup

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file: 
    MONGODB_URI=your_mongodb_connection_string
    PORT=3000
4. Start with `node server.js`
5. Open `http://localhost:3000`
